# Contributing

This repository contains security review notes and small reproduction programs. Contributions that improve accuracy or reproducibility are welcome.

Before opening a pull request, describe the affected source revision, the exact claim being changed, and the evidence supporting it. Keep historical observations distinct from a new reproduction. For code changes, use small focused commits, format Rust with `rustfmt` and Python with a standard formatter, and explain how to run any relevant check. Follow the relevant [librustzcash style guidance](https://github.com/zcash/librustzcash/blob/main/CONTRIBUTING.md#styleguides) for Rust and documentation where applicable.

Please do not include credentials, private keys, personal data, or unreviewed claims of an exploitable vulnerability in a pull request. For a potentially sensitive new finding, follow the affected upstream project's security reporting process first. Corrections to already public claims can be proposed through an issue or pull request here.
